# Skyline Architect

An original, native vertical-building management simulation for macOS (primary) and
iPadOS. Swift · SwiftUI · SpriteKit. No third-party engines.

- **Open** `SkylineArchitect.xcodeproj` in Xcode 16+ and run the `SkylineArchitect` scheme (My Mac).
- **Test** engine code: `Scripts/test-package.sh` (also works on Linux).
- **Read** `CLAUDE.md`, `Development/STATUS.md` and `Documentation/` before contributing.

Current state: see [Development/STATUS.md](Development/STATUS.md).
