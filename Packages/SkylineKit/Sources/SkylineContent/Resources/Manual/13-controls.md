# Keyboard and mouse

## Keys in the game view (Mac)

| Key | Action |
|---|---|
| `W` `A` `S` `D` or arrow keys | Pan |
| `Q` / `-` | Zoom out |
| `E` / `=` | Zoom in |
| `F` | Floor tool on or off |
| `X` | Demolish tool on or off |
| `Esc` | Put the tool away and clear the selection |
| `G` | Architectural grid |
| `Space` | Pause or resume |
| `1` – `6` | 1×, 2×, 4×, 10×, 30×, 60× |

## Mouse and trackpad (Mac)

| Input | Action |
|---|---|
| Two-finger scroll | Pan |
| Pinch, or `⌘`/`⌥` + scroll | Zoom at the cursor |
| Mouse wheel | Zoom at the cursor |
| Drag | Pan (with a build tool: place; drag with the right button to pan) |
| Click | Select a room |
| Right-click while placing | Cancel the placement |

## Menu shortcuts (Mac)

| Shortcut | Command |
|---|---|
| `⌘N` | New Game |
| `⌘S` | Save |
| `⌘O` | Load Game… |
| `⌘Z` / `⇧⌘Z` | Undo / Redo construction |
| `⌘?` | Skyline Architect Manual |
| `⌘=` / `⌘-` | Zoom in / out |
| `⌘0` | Reset view |
| `⌘1` `⌘2` `⌘3` `⌘4` | Site Overview, Foundation, Detail Close-up, Skyline |
| `⌥⌘G` | Architectural grid |
| `⌥⌘T` | Elevator traffic |
| `⌥⌘E` | Elevator banks |
| `⌥⌘L` | Leasing |
| `⌥⌘O` | Objectives (in a scenario) |
| `⌥⌘K` | Estate |
| `⌥⌘I` | Incidents |
| `⌥⌘P` | Standing |
| `⌥⌘M` | Economy |
| `⌥⌘F` | Facilities |
| `⌥⌘U` | Services overlay |

## iPad

| Input | Action |
|---|---|
| Drag with one or two fingers | Pan |
| Pinch | Zoom |
| Tap | Select a room |
| With a build tool: drag with one finger | Place |
| With a build tool: tap | Place at the usual size |
| With a build tool: two fingers | Pan |

The buttons at the bottom right open every panel and overlay. Keyboard shortcuts on an iPad keyboard are not supported yet.
