# Mods

Mods are **content packs**: folders of JSON files that add or change cities, plots, rooms, tenants, elevators, scenarios and more. They contain data only, never code, so a mod cannot harm your computer.

## Installing

1. Open **Mods…** from the main menu or the File menu.
2. Put each mod's folder into the mods folder. On a Mac, **Open Folder** shows it in Finder. On an iPad or iPhone, open the **Files** app and go to *On My iPad* (or *iPhone*) ▸ *Skyline Architect* ▸ *Mods*. Or press **Install Examples** to add the example mod, *Kestrel Bay*.
3. Press **Rescan**, turn the mods you want **On**, and put them in order with the arrows: later mods win.
4. Press **Apply**. The game reloads its content and starts a new game, so save first.

## What a mod can do

- Add new entries (a city, a room type, a scenario) or replace base entries with the same id.
- Replace whole rule files, such as the economy or the weather.

A mod with a mistake is skipped and the manager says why ("Not loaded: …"); the other mods and the base game still load.

## Saves and mods

A save remembers which mods it was made with. Loading it without one of them is refused and names the missing mod. If a mod changed since the save, the game tells you but loads it.

The example mod adds the city of Kestrel Bay with a plot for sale, a Loft Apartment, a creative household that rents lofts and the scenario *Kestrel Lofts*.

Making your own mods is described in the game's modding guide (Documentation/MODDING.md).
